# MediAlert+ 💊

An accessible medicine alarm and medication management app.

## 🎯 Problem Statement
People who take medicines regularly may forget doses or find it difficult to manage multiple schedules. MediAlert+ aims to make medication routines easier for users and their caregivers.

## ✨ Planned Features
- Medicine scheduling and recurring alarms
- Alarm sound with a stop button
- Medication history and tracking
- Family caregiver monitoring
- Prescription scanning
- Accessible, user-friendly interface

## 🛠️ Technology Stack
- Android development
- Java
- XML layouts
- Additional technologies to be documented as implemented
